# music.toffler.dev
Static showcase of AI-made music (artist: Barney Hendrickson), CC BY-NC 4.0. Streaming MP3s ship in `audio/`;
FLAC/WAV downloads live in GitHub Release `r1` (files in `release_assets/`, gitignored, 25 MiB Pages file limit).
Deploy = push to main (Cloudflare Pages project `toffler-music`). Rollback = Pages dashboard > Deployments > previous > Rollback, or `git revert`.
